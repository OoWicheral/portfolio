Pokédex com Webstorage

Pokédex simples que permite a criação e gerenciamento de equipes e pokémons, utilizandos dados provenientes da API PokéAPI.

Categoria Desenvolvimento Frontend
Contexto Estudo sobre WebStorage e API's REST
Ano 2026
Imagem Principal / Banner do Projeto

Sobre o Projeto

Esse projeto foi desenvolvido com foco no aprendizado sobre o funcionamento do WebStorage, explorado nas aulas de Desenovolvimento Web no segundo semestre do curso de Engenharia de Software da PUCPR. Nele, também busquei utilizar a PokéAPI para aquisição dos dados de cada Pokémon.

Projeto individual, onde utilizei HTML, CSS e JavaScript para construção da página e requisições da PokéAPI, o Google Gemini também fez parte do projeto, onde foi fundamental na revisão de código e prototipação da página.

Tecnologias Utilizadas

  • HTML5
  • CSS3
  • JavaScript
