Sobre o Projeto

Criado em equipe, após o reconhecimento da falta de acessibilidade ofertada de forma acessível para deficientes visuais na internet. O BlindNet é uma extensão web desenvolvida para mitigar esse problema, configurada para funcionar através de uma inicialização simples e rápida, realizando a leitura dos elementos presentes no corpo da página.

Atuei como o principal desenvolvedor, utilizando de JavaScript para o desenvolvimento da extensão. Também contribui para a documentação do projeto

Tecnologias Utilizadas
