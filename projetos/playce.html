Sobre o Projeto

O Playce foi desenvolvido com o objetivo de otimizar a gestão de quadras esportivas e controle de estoque de materiais alugáveis. O sistema resolve problemas como conflito de horários de agendamento e perda de controle de insumos. Eu e minha equipe desenvolvemos o projeto para o TDE de Raciocínio Algorítmico, matéria do 1º Semestre do curso de Engenharia de Software.

No projeto, fui responsável por desenvolver o módulo de administração, durante o desenvolvimento, pude aprender mais tanto sobre backend, quanto sobre frontend. O projeto foi desenvolvido utilizando HTML, CSS e JavaScript no frontend, e o framework Python Django para o backend. Utilizei o Google Gemini, para auxílio na prototipação da página web, na revisão de código e como consultor.

Tecnologias Utilizadas

  • HTML5 / CSS3 Puro
  • JavaScript
  • Python
  • Django
  • SQLite
  • Git & GitHub
